---
name: GitHub HTML payload filtering
description: Why the Netlify entry document is generated during build instead of stored as a source HTML file.
---

GitHub connector writes can return a Cloudflare 403 whenever an API payload decodes to a complete HTML document, across Contents, Git Data, and GraphQL endpoints.

**Why:** Repeated upload approaches failed specifically on complete HTML payloads, while normal source, binary assets, and repository metadata uploaded successfully. GitHub's legacy Repository Import API is also deprecated.

**How to apply:** Keep the Bobal Stav entry document generated by the prebuild script and ignored by Git. For future repository updates, upload source files through the connector and verify with a clean clone plus the Netlify build command.
